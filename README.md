### 🌾 **[Smart Kishan - Crop Recommendation System](https://github.com/adarisamuelprasad/smart-crop-recommendation)**
> *AI-powered agricultural advisory for Indian farmers*

An inclusive farming platform designed for uneducated and semi-educated farmers with:
- **Zero Typing Interface** – Visual sliders, icons, and big buttons
- **Multilingual Support** – Hindi, Telugu, Tamil, Kannada, Marathi, Gujarati, Bengali, Punjabi, and more
- **Voice Guidance** – Speaks instructions and results for accessibility
- **Smart Recommendations** – AI-driven crop suggestions based on soil (N, P, K, pH) and weather (temperature, rainfall, humidity)
- **Offline Capable** – PWA-ready lightweight design

**Tech Stack:** Next.js 14, Vanilla CSS, Web Speech API, ML Logic Engine  
**Impact:** Democratizing agricultural technology for rural communities
